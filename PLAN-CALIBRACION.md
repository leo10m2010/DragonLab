Para cada modalidad: varias fuerzas, validación con tiros reservados, ángulos medios/altos, viento de distintas direcciones y comprobación de contactos con jugadores y terreno. Los resultados se guardan por juego, carro y modalidad. No se considera completa una calibración de lanzamiento como si también validara comportamientos especiales o todos los impactos.

Random se revisará para identificar el carro asignado antes de decidir qué perfil calibrar. La lista muestra opciones del selector; aún no confirma el comportamiento físico de cada opción.
